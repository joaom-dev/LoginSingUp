# 🔐 Authentication System  (React & Java Spring) 

A back-end application developed with Java and Spring Boot, focused on user authentication, access control, and security practices.

---

## 📌 About the Project

This website is a strictly educational project. The data entered here (email and password) is stored as a hash in a test database, solely to demonstrate how the login system works. No data will be sold, shared, or used for any real-world purposes. For your own security, please do not use the actual passwords you employ for other services here.

---

## 🚀 Features

-  User registration
-  User login and authentication
-  Password hashing using BCrypt
-  JWT (JSON Web Token) authentication
-  Endpoint protection with Spring Security
-  Role-based access control
-  User data persistence with MySQL

## 🏗️ Architecture

The application follows a layered architecture, separating responsibilities to improve code organization, maintainability, and scalability.

### 📂 Main Layers

-  **Controller:** handles HTTP requests and API responses.
-  **Service:** contains business logic and application rules.
-  **Repository:** manages data access and database operations.
-  **Entity:** represents the application's data entities.
-  **DTO (Data Transfer Object):** structures data exchanged between the client and the API.
-  **Security:** contains components responsible for authentication, token validation, and access control.

---

## 🔐 Authentication & Security

- 🎟️ **JWT (JSON Web Token):** Token-based authentication for accessing protected endpoints.
- 🔑 **BCrypt:** Password hashing for secure credential storage.
- 🛡️ **Spring Security:** Authentication and access protection.
- 👥 **Role-Based Access Control:** Permission management based on user roles.

---

## 🗄️ Database Structure

**Database:** MySQL

User data is stored in a relational database, supporting user registration, authentication, and role-based access control.
